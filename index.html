⌨️ ADB komutları (ileri seviye, PC gerekir)

Bilgisayara Android Studio Platform-Tools kur, telefonda Geliştirici seçenekleri → USB hata ayıklama'yı aç, komutları kopyala-yapıştır çalıştır. ADB indir

MIUI optimizasyonunu kapat

adb shell settings put secure miui_optimization 0

Pil muafiyet listesine ekle

adb shell dumpsys deviceidle whitelist +com.google.android.projection.gearhead

USB yapılandırmasını MTP yap

adb shell settings put secure usb_default_config mtp

Android Auto önbelleğini sıfırla

adb shell pm clear com.google.android.projection.gearhead
